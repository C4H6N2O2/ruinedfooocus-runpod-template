# RuinedFooocus RunPod Template 🚀

This template automatically starts:

- **RuinedFooocus** on port `3000`
- **RunPod File Uploader** on port `2999`
- **JupyterLab** on port `8888`

The container is built on **CUDA 12.4** and is compatible with both **NVIDIA RTX A5000** and **RTX 5090** GPUs.
